Features

Everything you need to post daily

One long episode in — a batch of ready-to-publish clips out, each with a title, hook, caption, and hashtags.

🎧

Local transcription

Whisper turns speech into a timestamped transcript right on your machine — works offline after a one-time model download.

🔍

Smart moment scoring

A built-in engine scores every moment for hooks, questions, emotional language, and energy. No AI service, no key, no cost.

✂️

Sentence-safe cutting

FFmpeg cuts clips in 9:16, 1:1, or 16:9 with watermarks and loudness normalization — and never chops a sentence in half.

💬

Styled burned captions

Four caption styles with position and size controls, plus .srt subtitle export for every clip.

📝

Post captions written

Every clip ships with a title, hook line, copy-ready social caption, and hashtags. Copy, paste, post.

📚

Clip library

Every past job is saved and browsable, with a searchable transcript explorer and optional YouTube import.

How it works

Four steps. Zero accounts.

The whole pipeline runs on your computer — your video never leaves your machine.

Drop in your episode

Upload a video file or paste a YouTube link into the app.

It finds the gold

Whisper transcribes, then the scoring engine picks the most clip-worthy moments.

Clips are forged

FFmpeg cuts vertical clips and burns styled captions automatically.

Download & post

Grab the MP4s, copy the ready-made captions and hashtags, and publish.

Get started

Running in about 2 minutes

You need Python 3.10+ and FFmpeg installed. That's it — no sign-ups, no API keys.

terminal 
git clone https://github.com/ygirma315-cell/JOAIPODCAST.git
cd JOAIPODCAST
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py

On Windows, activate with .\.venv\Scripts\Activate.ps1 instead. Need FFmpeg? brew install ffmpeg · winget install FFmpeg · sudo apt install ffmpeg

🖥️ Why does the app run on my computer instead of this website?

Cutting video and transcribing audio are heavy jobs — they need real processing power and tools like FFmpeg and Whisper that browsers can't run. Cloud services that do this charge monthly fees precisely because that compute is expensive.

ClipForge skips all of that: your own computer does the work, so it's free forever — no subscriptions, no upload limits, no privacy worries. This page is the front door; the forge is on your machine.
